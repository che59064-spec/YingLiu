# 提示词优化规则来源

核对日期：2026-10-26。只采用模型发布方的文档与官方仓库；规则以自行概括的形式保存于 `prompt_rules.json`，没有整段复制官方系统提示词。

## MiniMax H3

参考生成采用[官方完整参考指南](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/ref-en.txt)：区分人物外观、动作、场景与声音的来源，保持引用编号一致，按六个有序部分描述目标。文字、首帧及首尾帧生成采用[官方基础模式指南](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/base-en.txt)，包含三个主要部分和相应帧时间锚点。

说明性正文按官方约定使用英文，用户指定的对白、歌词和画面文字保留原文。参考图与动作视频的职责必须明确；这属于语义约束，不能保证人物被强制锁定或动作逐帧复刻。

## 千问图像 2.1

已核对[Qwen-Image-2.1 官方仓库](https://github.com/QwenLM/Qwen-Image-2.1)与[官方改写工具说明](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/prompt_rewrite/README.md)，对应当前本地千问图像 2.1 工作流，不采用千问聊天模型规范或旧版图像规则代替。

[文生图规范](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/prompt_rewrite/prompts/system_prompt_t2i.txt)要求用英文描述完成后的画面，并明确主体、空间位置、材质与光线。图像里实际显示的文字逐字保留原语言并加双引号，比例与分辨率不混入画面描述。

[编辑规范](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/prompt_rewrite/prompts/system_prompt_edit.txt)要求中文请求使用中文编辑指令。编辑对象、改变的属性与保留部分需要明确；人物和产品身份优先通过对应图片引用，而非重新描写。多图编号必须与真实输入顺序一致。

文生图和编辑的语言规则不同。界面显示完整中文对照；送给生成模型的提示词按实际任务规范处理。中文对照与引擎文本由同一次优化请求返回，不以摘要代替全文。

## 本软件的额外约束

优化不得改掉用户已指定的意图、数量、人物关系、时长、画幅或文字。优化器未实际看到素材时，只能使用用户描述和已确认的参考关系，不能根据文件名猜测长相、动作或背景；缺失信息必须单独提示。优化结果先供用户查看，不自动启动图片或视频生成，也不保证优化后的成片质量。

本地规则是上述官方规范的保守子集。为适配已有画布，它不擅自调整采样、模型、分辨率或宽高比；需要变更时应作为建议单独展示。

## Agnes 素材理解

[Agnes 3.0 官方接口说明](https://wiki.agnes-ai.com/en/docs/agnes-30-flash)列出了文字与 image_url 图片输入，未列出原始视频输入。软件通过图片内容块提供参考图片；视频只在所选时间段内抽取 12 帧，标记所属视频和原片时间。它不能听到视频音轨，不能保证还原采样帧之间的细节；界面明确显示范围、帧数和音频限制。人物替换时，参考图优先定义目标身份，视频只提供用户要求的动作和空间关系。
