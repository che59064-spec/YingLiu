# GitHub 发布准备

`scripts/package_release.py` 生成独立的干净目录与 ZIP。请将 `YingLiu-版本-source` 中的文件作为仓库根目录上传，不要上传个人工作目录的上级目录，也不要上传整个 `data/`。

源码发布目录排除了本机配置、密钥、画布、任务记录、参考素材、模型、个人截图与旧安装文件，并生成逐文件 SHA256 清单。说明文档中的启动预览和流程示意图不包含用户素材。Windows 便携包只额外包含新构建的 `映流.exe`、来源固定且校验过的 WebView2 DLL 和 Microsoft 许可文件，不包含用户数据。

映流自身源码采用 MIT 许可证。同步桥依赖的第三方组件和个人导入工作流的模型不包含在源码包中。分享示例工作流前需要确认其中的提示词、文件名、路径、API 节点凭据和第三方授权。

建议 GitHub Release 同时提供源码包、Windows 便携包、各文件的 SHA256 清单，以及清楚的依赖要求。该版本没有代码签名，Windows 可能显示未知发布者。此包是需要外部运行环境的应用，不是包含全部 AI 模型的一键安装器。

发布前在没有个人 `config.json` 和 `data/` 的新目录测试：能打开空白画布、配置自己的引擎、导入一个工作流、查看缺失依赖、配置可用的 AI。真实生成与真实付费 API 测试应由发布者按自己的环境和账户进行；自动测试只使用隔离数据和模拟接口。
